# Проект Love - Требования

## Описание
Милый сайт-признание в любви, выполненный в пастельно-розовых тонах с сердечками и котиками.

## Технический стек
- **HTML5** - структура страницы
- **CSS3** - стилизация с пастельно-розовой цветовой гаммой
- **JavaScript** - интерактивные элементы (анимация сердечек)

## Требования к странице

### Структура
- Центральное письмо с признанием в любви
- Фон с сердечками
- Картинки милых котиков, целующихся
- Анимированные сердечки

### Цветовая палитра
- Основной фон: пастельно-розовый (#FFD1DC или #FADADD)
- Текст: темно-розовый (#C2185B или #880E4F)
- Акценты: светло-розовый (#FFB6C1)

### Контент
- Милые и любящие тексты
- Изображения котиков (можно использовать ссылки на Unsplash или аналоги)
- Анимация плавающих сердечек

### Функциональность
- Работает локально (file://)
- Адаптивный дизайн для мобильных устройств
- Легкая анимация сердечек на фоне
